# AI Trainer - PWA

Это React + TypeScript приложение "AI-Тренер" для фитнес-тренировок с AI интеграцией.

## Технологический стек

- **Build**: Vite + React + TypeScript
- **State Management**: Zustand
- **Router**: React Router v6+
- **PWA**: vite-plugin-pwa
- **Database**: Dexie (IndexedDB)
- **Forms/Validation**: react-hook-form + zod (планируется)
- **UI**: Tailwind CSS + Headless UI
- **Dates**: date-fns
- **HTTP/AI**: fetch + AbortController
- **i18n**: Zustand store с переводами (ru/en)
- **Icons**: lucide-react (планируется)

## Настройка AI (OpenAI)

Для работы AI функций необходимо настроить API ключ OpenAI:

### Вариант 1: Переменные окружения (рекомендуется для продакшена)

1. Создайте файл `.env` в корне проекта:
```bash
# OpenAI API Configuration
VITE_OPENAI_API_KEY=sk-ваш-ключ-openai-здесь
```

2. Замените `sk-ваш-ключ-openai-здесь` на ваш реальный API ключ OpenAI

### Вариант 2: Настройка через интерфейс (для разработки)

1. Запустите приложение
2. Перейдите в Настройки
3. Введите ваш OpenAI API ключ в соответствующее поле
4. Ключ будет сохранен в localStorage браузера

**Примечание:** Файл `.env` автоматически игнорируется Git для безопасности.

### Получение API ключа OpenAI

1. Зарегистрируйтесь на [OpenAI Platform](https://platform.openai.com)
2. Перейдите в раздел API Keys
3. Создайте новый ключ
4. Скопируйте ключ (он показывается только один раз!)
